# Magnetizer-V2
A remastered version of my original Magnetizer mod, with my improved modding skills.
The reason why it's not just an update is because it's a bit more complicated to use, and Teardown's own featured mod section's mod guide would have to be updated to reflect the changes (which I have no access to do).

## What's different compared to v1?
- Added magnet modes
- Added options to menu
- Added the ability to select through walls
- Added the ability to hold down the select button
- Added electricity sparks (they can be disabled)
- Added the ability to view controls
- Added moving parts to the tool
- Added/changed sounds
- Reworked the menu
- Reworked physics
- Changed the model
- Changed animations
- Changed the branding from Magnetizer to Magnetizer V2
- Replaced the power sliders to a power wheel
- Made saving only apply to switches
- Removed the confusing gain system
